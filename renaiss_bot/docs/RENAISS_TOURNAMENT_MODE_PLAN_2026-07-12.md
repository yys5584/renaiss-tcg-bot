## 핵심 컨셉

> **"라스트 비드(Last Bid)" — 상한 이하 카드를 순서대로 공개하며 덮어쓰는 눈치싸움.**
> 규칙 한 줄: "오늘 상한 $100. 순서대로 카드 1장씩 공개 — 상한 이하 최고가가 승리."

- 동시 제출(조회 게임)이 아니라 **순차 공개(심리 게임)**: 뒷순서는 앞 카드를 보고 "살짝 덮을지" 결정. One Bid + 더 지니어스 검증 구조.
- 컬렉션 가치 반영: 상한 근처에 "붙은" 카드를 보유·파악한 사람이 이김 = 수집 폭 + 시세 리터러시.
- 체급 분리: **라이트 리그($100 이하 상한 로테이션)** / **오픈 리그(주 1회, 무제한 — $85k 차리자드 강림의 축제)**.

## 상세 설계 (매일 22:00 KST, 총 ~10분)

1. **21:00 접수 공지** — "오늘 밤 라스트 비드, 상한 $100" (참가 버튼, 준비물 없음)
2. **22:00 라운드 1** — 참가자 랜덤 순서 배정. 봇이 순서대로 호명, 각자 DM 버튼으로 카드 선택(20초) → 그룹에 즉시 공개(슬랩 렌더). 뒷순서는 앞 카드를 보며 선택.
3. **오버 시 즉사**: 상한 초과 카드는 제출 불가(봇이 필터) — 대신 "패스" 선택 시 그 라운드 최하위.
4. **라운드 2~3** — 상위 절반 진출, 상한이 매 라운드 하락($100→$60→$40): 갈수록 "낮은 체급 에이스"가 필요 → 컬렉션 깊이 검증. 같은 카드 재사용 불가.
5. **우승**: 시즌 풀 랜덤 카드 + "오늘의 챔피언" 발표 + 카드 커리어 기록("이 카드로 3승").
6. **전원 참가 보상**: 소액 (챔피언스미팅 원칙). 미참여 페널티 없음.
7. **관전 장치**: 각 공개 직전 관전자용 "이 카드 얼마게?" 버튼 투표 — 맞춘 관전자에게 포인트 (Costcodle 원리, 대리깡 관전층 흡수).

주간 확장(2단계): 일요일 오픈 리그 — 데일리 우승자 8인 브래킷, 라운드마다 상한 상승($100→$1,000→무제한 결승).

## 구현 범위 (예상)

- DB: `renaiss_tournaments`, `renaiss_tournament_entries`(라운드·제출카드·순서), 카드 커리어는 entries 재활용
- 파일: `handlers/tournament.py`(신규), `jobs.py`(21시/22시 잡 2개), `database/queries.py`(예약·판정), 렌더 재사용
- env: `RENAISS_TOURNAMENT_ENABLED`, 상한 로테이션 목록
- 난이도: **M** (스폰·flex의 예약/버튼/렌더 인프라 재사용 가능)

## 리스크 / 고려사항

- 참가 2인 미만 → 자동 취소·보상 없음 (쿠키런 교훈: 강제 없음)
- 순차 공개는 참가자 많으면 길어짐 → 8인 초과 시 조별 동시 진행 또는 제한 시간 단축 (수치 조절 필요)
- 동가 무승부: 7일 상승률 → 선제출 순 (조절 필요)
- 시세 갱신(일 2회)으로 상한 걸친 카드가 오락가락 — "스냅샷 시점 가격 기준" 명시 필요
