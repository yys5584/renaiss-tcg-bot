2026-07-08 · 무대: 르네이스 공식방 (영어) · 심장 전환: "잡는 게임" → "트레이딩 게임" · 이전 기획 RENAISS_SEASON1_REVIVAL은 이 문서로 대체 (강스는 수입원으로 흡수)

1. 왜 트레이딩이 심장인가

르네이스 타겟은 코인 유저다. 리서치에서 확인됨 — 이들은 PnL 인증·페이퍼 트레이딩 대회·수익률 랭킹에 본능적으로 반응한다(TradingView 가짜돈 대회가 굴러가는 이유). 낭만이 아니라 본토다.

- 정체성 선명: "포인트 모으기"(RP) → "자산 불리기"($). 실시세가 게임의 전부가 됨.
- 조작 불가: 시세를 서버가 검증 → 코인판 "가짜 스크린샷" 문제 원천 차단. "진짜 실력 트레이더 랭킹"이 성립.
- 강스는 안 버림: 이미 만든 강스 사냥(1단계-a)은 "무료 카드 수입원"으로 역할만 바뀜.
데이터 근거 (2026 3~4월 baseline — 살아있던 시기): DAU ≈ 110명(피크 263) · 21~22시 일별 순유저 ≈ 32명(라이브 마켓 아워 관중 충분) · 매일 대회(21:50)가 "9시 집결"을 이미 학습 · 집중도 TOP15 47%/TOP50 75%인데 활동유저 872명(캐주얼 롱테일 실재) · 최상위 15인은 100~220 포획/일 극한 그라인더. → 목표 = 이 규모(~110 DAU)를 신규 코인 유저+복귀로 재현. (현재 DAU~10은 시즌2로 붕괴한 값이라 baseline 아님)

2. 게임 구조 — 3층

층언제역할
강스 사냥 (잡기)낮 상시공식방에서 c/m로 무료 카드 확보 = 자본·인벤토리
트레이딩 (사고팔기)상시 + 마켓 아워가상 $로 카드 사고팔기. 킵 vs 팔기 결정
트레이딩 장 (데일리)매일 21:00~24:00오늘 갱신된 실시세에 반응해 3시간 사고팔며 겨룸 → 일일 챔피언

메타 목표 = 순자산 랭킹 (현금 $ + 보유 카드 시세). 시즌 리셋.

[낮] 강스로 카드 잡음 (자본 축적) → 킵할지 시장에 팔지 결정
[밤 9~12시] "🔔 Market open!" → 오늘 실시세 소식에 반응해 3시간 사고팔며 순자산 불리기
[밤 10시] "Market close" → 일일 챔피언 발표, 시즌 랭킹 갱신
[반복] "내일 장 열리기 전에 강스로 자본 더 모아야지"

2.5 설계 제1원칙 — 단순함 + 단계별 자연 공개 ⭐

새 유저한테 트레이딩 시스템 전체를 들이밀면 죽는다(철학: "c만 누르는 유저 기준"). 입구는 "수집이 재밌다" 하나. 다음 층은 유저가 준비됐을 때 봇이 자연스럽게 연다.

단계유저가 하는 것봇이 여는 다음 스텝
Lv0 수집카드 뜸 → c → 잡음 (설명 0, 즉시 재미)—
Lv1 가치 발견잡은 카드에 시세가 붙어있네?"네 컬렉션 = $340" 슬쩍 노출
Lv2 첫 결정비싼 카드 잡음"Sell $120 or Keep?" → $ 통화 등장
Lv3 트레이딩$ 생김"오를 것 같은 카드 사볼래?" → 사고팔기
Lv4 트레이딩 장+랭킹트레이딩 재미 붙음"밤 9~12시 장 오픈, 오늘 챔피언 도전"
- 캐주얼은 Lv0~1에 평생 머물러도 재밌음 — 절대 뒤처지는 느낌 X.
- 파는 사람은 Lv4까지 자연스럽게 빨려듦 — 강요 아니라 발견.
- 각 단계 조작 = 버튼 1~2개. 차트 읽기·복잡 주문 없음.
- Lv0~2(수집+솔로 팔기) = 저인구에서도 도는 바닥 / Lv4(마켓 아워) = 인구 차면 켜지는 심장. 깔때기가 솔로/라이브를 자동 순서 세움.

2.7 코어 메커닉 — 블라인드 잡기 + 베스트10 굴리기 ⭐

낮 = 가격 가린 채 안목으로 잡기:
- 카드가 가격 없이 뜬다 (뭔 카드인지만 보임). "이거 값나갈 것 같은데?"를 내 지식으로 판단해 잡거나 흘려보냄.
- 슬롯 10칸. 새 카드가 내 최악 카드보다 나으면 교체 → 버리는 게 아니라 "더 좋은 걸로 갈아끼우기"(가챠 리롤·포트폴리오 최적화의 중독 루프).
- 하루 종일 내 베스트 10을 다듬는 것이 코어. 레벨업 = 슬롯 확장 + 베네핏.
왜 이게 공모전에 최적인가:
- 안목 = 실력 → 시세 아는 사람이 잘함. 뉴비는 밤 공개로 배우며 성장(지는 게 벌이 아니라 배움) = 르네이스 시세 교육 퍼널.
- "내 10장"이 딱 보임 → 심사자에게 9000장보다 임팩트. 스샷 한 장으로 자랑 = 바이럴 최적.
- 10칸이 whale 재고를 자연 평탄화(단, 처리량은 못 막음 → 일일 잡기 캡과 세트 필요, §7).

2.8 바이럴 엔진 — "많은 유저"가 상금 조건

개인은 "베스트 10 굴리기"로 붙잡고, 확산은 자랑·순위·우르르로:
- 내 10장 순자산 자랑 (스샷) → 보는 사람 "나도 해볼까"
- 밤 순위 경쟁 → 이기려면 사람이 많아야 재밌음 → "너도 들어와"
- 그레일 뜨면 방 전체 알림 → 구경하러 옴 (우르르)
- 카드에 "진짜 카드 르네이스에서 보기" 버튼(레퍼럴) → 유입 트래픽까지 르네이스로

3. 통화 — RP → 가상 $ (페이퍼)

- 기존 RP 개념을 가상 달러($)로 전환. 강스 보상·거래 수익 다 $ 단위.
- 철저히 페이퍼: 랭킹·자랑용 가상 자산. 현금 인출 절대 없음 (아래 §7 선).
- 시작 자본: 신규는 소액 $ + 강스로 잡은 카드로 출발.

4. 강스 사냥 = 수입원 (이미 구현)

1단계-a로 만든 것: 공식방 1분 상시 스폰 + c 잡기 + 시세 밴드(일반/레어/그레일). 그대로 쓰되 역할 재정의 — 잡은 카드는 "팔아서 $ 만들거나 오를 때까지 킵"하는 자본이다.
- m(마스터 풀)로 고가 카드 확정 획득 = 좋은 자본 확보.
- 강스는 "게임의 심장"이 아니라 "매일 장에 들고 갈 실탄을 버는 곳".

5. 트레이딩 — 사고팔기

- 팔기: 보유 카드를 시장에 판다. 시세의 N%로 매입(예: 60% — 현실 카드샵도 싸게 사서 마진 남김) → $ 확보 + RP 인플레 방지.
- 사기: 다른 유저가 아니라 NPC 시장에서 실시세로 산다(P2P 아님 — 고래 착취·조작 차단). 오를 것 같은 카드를 밤 장에서 매수.
- 킵 vs 팔기 긴장(TCG Card Shop Simulator의 심장): "이 $500 그레일, 자랑·순자산용으로 킵할까 팔아서 실탄 만들까?"

6. 하루 리듬 — 낮엔 사냥, 밤 9~12시는 장 (핵심)

낮 = 카드 사냥(자본 축적) / 매일 밤 21:00~24:00 KST = 트레이딩 장 오픈 (3시간). 실측 활동 피크(9시~자정)에 트레이딩을 몰아넣어 "다 같이 거래하는" 크라우드를 만든다.

실시세로 어떻게 움직이나 (시뮬 아님): 실제 카드 시세는 하루 안엔 거의 안 변한다. 그래서 매일 밤 21:00 "장 오픈" = 그날 실제로 갱신된 시세를 봇이 뿌리는 순간 — "📈 오늘의 무버: Charizard +8%". 3시간 창은 그 오늘의 진짜 소식에 반응해 사고파는 시간. 개별 수익은 며칠에 걸쳐 진짜로 나고(실시세), 이 창은 판단·거래·경쟁을 다 같이 하는 소셜 이벤트. 가짜 가격 안 그림 → 정체성 유지.
흐름:
1. 낮: c/m로 카드 잡아 자본·인벤토리 축적 ("장 열리기 전에 실탄 챙기자")
2. 21:00 "🔔 Market open" — 오늘 갱신된 실시세 + 무버 공개
3. 21:00~24:00: buy/sell로 오늘 소식에 반응해 포지션 조정. 순위판 실시간, 방이 살아있음
4. 24:00 "Market close" — 그날 순위 정산·자랑. 수익 확정은 이후 며칠 실시세로
드라마 = 진짜 시장 뉴스: 실제 카드가 튀는 이유(대회 메타·재입고·유튜버 띄움·세트 로테)를 봇이 surface → "왜 올랐나"까지 배움. 가짜 급등락이 아니라 진짜 시장을 읽는 재미. "놀다 보면 시세를 배운다"가 여기서 완성.

7. 순자산 랭킹 + 넘으면 안 되는 선

랭킹기준
일일 챔피언그날 마켓 아워 순자산 상승률 % (모두 동등 출발감 → 뉴비도 잘 하면 1등, 격차 0)
시즌 랭킹누적 순자산($+보유카드). 고인물 앞서나 주/월 시즌 리셋으로 영구 지배 방지
이 방향의 3대 필수선 (못 넘음):
① 페이퍼 트레이딩만 — 가상 $, 랭킹·자랑용. 현금 인출 0. 넘으면 도박법·P2E 기생충·시세조작 다 터짐.
② 시세 신뢰도 = 생명줄 — 게임 전체가 실시세 위. 신뢰도 높은 카드만 거래. 매일 밤 장 오픈 시 실시세 갱신이 정확해야 함(파트너 API 필요).
③ 랭킹 시즌 리셋 — 영구 순위 = 다수 이탈(리서치의 줄세우기 피로). 시즌제 필수.

9. 리스크

① 스코프. 거래 시스템(buy/sell)·일 1회 시세 갱신·랭킹을 새로 지어야 함. 큼 → 단계적.
② 시세 데이터 품질/접근. 게임 전체가 실시세 위 → 파트너 API(하루 10k, item-by-no 정확조회) 필수. 현재 무료 하루 10번은 부족(펜딩).
③ 트레이딩 진입장벽. "c만 누르던" 캐주얼에겐 사고팔기가 어려울 수 있음 → 프리마켓 워밍업·단순 UI로 완화. buy/sell은 버튼 2개 수준으로.
④ 수치 전부 초안. 매입율(%)·시작자본·틱 주기·뉴스 빈도·시즌 길이 다 조절.

10. 단계 (재정렬)

1강스 사냥 (✅ 1단계-a 완료) — 자본 수입원
2$ 전환 + 팔기 — RP→$, 카드 시장 매도(시세 N%), 킵 vs 팔기
3트레이딩 장 엔진 — 밤 9~12시 장 오픈, 일 1회 실시세 갱신, buy/sell, 순자산 실시간, 무버 공개
4랭킹 — 일일 챔피언 + 시즌 순자산 랭킹 + 리셋
5퀴즈=프리마켓 재배치, 플렉스·팩 연결, 밸런스
